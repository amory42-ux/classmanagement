# 🎮 자리왕 배틀 — 실시간 채널 & 교사 비밀 조작 학급 자리 관리 웹 앱

학생들은 각자의 태블릿으로 미니게임을 즐기며 "100% 공정한 랜덤 추첨"으로 자리가 정해진다고 느끼게 하고, 실제로는 **교사가 설정한 비밀 조건(앞자리 시력 고정, 기피 학생 분리, 남녀 성비 균등)**이 100% 반영되도록 마술처럼 연출하는 스마트 학급 자리 관리 시스템입니다.

---

## 🌟 핵심 기능 요약

### 1. 📡 실시간 채널(방 코드) & 태블릿 멀티플레이
- **무료 P2P 실시간 통신**: 별도의 유료 서버 없이 PeerJS(WebRTC)를 통해 GitHub Pages에서도 무료로 동작.
- **교사용 화면 (전자칠판/교탁 PC)**:
  - 4자리 방 번호(예: `ROOM: 7701`) 및 **QR 코드** 자동 생성.
  - 25대 학생 태블릿의 접속 상태 실시간 감지 및 게임/추첨 일괄 제어.
- **학생용 태블릿 화면**:
  - 접속 시 4자리 방 코드 입력(또는 QR 스캔) ➡️ 이름 선택 ➡️ 실시간 게임 및 결과 수신.

---

### 2. 🕵️‍♂️ 교사의 비밀 조작(지정 배치) 엔진 (Secret Rigging)
- **교사 관리자 진입**: 로비 상단 제목 `자리왕 배틀` 글자를 **5번 연속 클릭** (PIN: `100402`)
- **📌 앞자리 / 특정 좌석 강제 고정**:
  - 시력 배려, 수업 집중이 필요한 학생을 원하는 좌석에 100% 우선 고정.
- **🚫 기피 학생 분리 (앙숙 / 떠벌이 인접 금지)**:
  - 서로 붙어있으면 안 되는 학생들을 등록하면 인접 8방향 배치를 완벽하게 차단.
- **⚖️ 남녀 성비 밸런스 유지**:
  - 남 10명 : 여 15명 비율에 맞춘 5개 균등 모둠 및 좌석 배치.

---

### 3. 🎰 "완전 랜덤" 위장 마술 연출 (Fake Randomizer Effect)
- 학생들에게는 교탁 화면과 태블릿 전체에 **"🎲 실시간 AI 랜덤 자리 추첨"** 룰렛이 돌아가는 화려한 애니메이션이 표출됩니다.
- 룰렛이 멈출 때, 학생들은 순수 운/게임으로 뽑힌 줄 알지만 **교사가 설정한 비밀 규칙(고정석+분리조건)이 100% 충족된 배치표**가 마술처럼 도출됩니다.

## 🚀 사용 가이드

1. **교사 (전자칠판/교탁 PC)**:
   - 메인 화면에서 **`[👨‍🏫 교사용 대형화면 (방 만들기)]`** 클릭.
   - 화면에 뜨는 4자리 방 번호(또는 QR 코드)를 학생들에게 안내.
   - (선택) `[🔒 교사 비밀 관리자]`에서 앞자리 고정석이나 분리 학생을 미리 등록.
   - 학생들이 입장하면 `[⚡ 번개 반응 배틀]` 또는 `[🎲 즉시 비밀 자리 추첨]` 클릭!

2. **학생 (개별 태블릿)**:
   - 태블릿 브라우저로 접속 후 **`[📱 학생 태블릿으로 참여하기]`** 클릭.
   - 4자리 방 번호 입력 ➡️ 본인 이름 선택 ➡️ 대기실 입장 후 미니게임 플레이!
